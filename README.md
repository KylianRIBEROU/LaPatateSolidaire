# Maquette site web La Patate Solidaire

  This is a code bundle for Site web La Patate Solidaire. 
  
## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  
## Figma make

J'ai supprimé les intégrations figma make inutiles dans un projet normal non précompilé, tels que les ficheirs de conf tailwind de 1000 lignes,...

C'est peut-être normal si le projet n'est donc plus compilable sur figma make à la volée. Pour accéder aux maquettes, aller directement sur le projet de groupe Figma et utiliser le plugin de génération si besoin.

Sinon, pour accéder au site, lancer le projet normalement.
